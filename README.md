# Samsungdang DojoLog

아이키도 지도자를 위한 수업기록·수업구성 보조 앱입니다.

삼성당 1,000회 수련을 기념하여 제작했습니다.

## 현재 버전

v0.9.9
Android

삼성당에서는 제1,010회 수련부터 DojoLog를 통한 수업기록을 시작합니다.

## 주요 기능

- 참가 급수에 따른 수업구성안 제시
- 최근 수업기록을 고려한 카타 구성
- 평일 1시간 수업: 5카타
- 토요일 1시간 30분 수업: 7카타
- 수업일지 저장
- 본부 카타 검색
- 수업구성안에서 도주 시범영상 바로 확인
- 검/단도, 장, 2인 잡기 구성
- 삼성당 급수 심사표
- JSON 데이터 백업/복원

## v0.9.9에 대하여

현재 버전은 삼성당에서 실제 수업에 사용하기 위해 제작한 시험 배포 버전입니다.

따라서 현재는 삼성당 급수 심사표를 기준으로 수업구성안을 제시합니다.

다른 도장 지도자들의 사용 의견과 수요가 확인되면,
향후 v1.0에서는 각 지도자가 자신의 도장 심사표를 직접 입력하여
사용할 수 있는 범용 버전을 검토하고 있습니다.

## 주의사항

- 현재 Android용입니다.
- Google Play를 통한 배포가 아닌 APK 직접 설치 방식입니다.
- 중요한 수업기록은 JSON 백업 기능을 이용해 별도로 보관하는 것을 권장합니다.
